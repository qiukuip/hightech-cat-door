## 1. 概述

本系统由两套 ESP32-S3-CAM 节点组成：

| 节点 | 位置 | 角色 | 主要外设 |
|------|------|------|----------|
| `esp32out` | 门外 | 采集+触发 | 1× VL53L1X、光敏电阻、红外补光灯、OV2640（4 FPS 抓拍） |
| `esp32in`  | 门内 | 执行+触发 | 1× VL53L1X、2× 舵机、OV2640（雷达首次触发时拍单帧留存） |

两节点均通过 WiFi 接入局域网，连接到服务端 **同一端口** `<server-ip>:1234`。室外/室内身份在 TCP 建连后通过 `0x8` register 帧声明 (`0x00` outdoor / `0x01` indoor)，由服务端分类。完整协议见 `通信协议设计.md`，状态机见 `系统工作流程.md`。

> ESP32-S3 的 GPIO 工作电压为 3.3V。VL53L1X、光敏电阻、红外补光灯、SG90/MG996R 舵机信号线均为 3.3V 兼容；舵机供电请使用独立 5V/6V 电源（≥2A），**不要**直接从 ESP32 的 5V 引脚取电。

## 2. 门外节点（`esp32out`）连线

### 2.1 GPIO 总览

| GPIO | 用途 | 方向 | 备注 |
|------|------|------|------|
| GPIO1  | I2C SDA              | I/O  | 雷达总线数据 |
| GPIO2  | I2C SCL              | OUT  | 雷达总线时钟 |
| GPIO3  | 光敏电阻 ADC         | IN   | ADC1_CH2（ESP32-S3 strapping pin，详见 §5.9） |
| GPIO38 | VL53L1X XSHUT        | OUT  | 上电时拉低→高，启用 |
| GPIO39 | 保留                 | —    | 当前悬空，留作未来 XSHUT2 |
| GPIO47 | 红外补光灯           | OUT  | 高电平点亮 |

摄像头占用 GPIO4-13、15-18（板载，不可改动）。

### 2.2 模块连接

#### VL53L1X × 1（激光雷达）

VL53L1X 默认 I2C 地址为 `0x29`，单传感器直接使用默认地址即可，**无需** XSHUT 时序分配地址。GPIO39 当前悬空，可留作未来扩展。

| VL53L1X 引脚 | 连接 |
|--------------|------|
| VIN          | 3.3V |
| GND          | GND  |
| SDA          | GPIO1 (I2C SDA) |
| SCL          | GPIO2 (I2C SCL) |
| GPIO1 (INT)  | 不接 |
| **XSHUT**    | GPIO38 |

初始化：`XSHUT = LOW` 保持 10 ms → `HIGH` 保持 10 ms → `radar1.init()` → 设为短距模式 (`Short`)，然后设置**测量预算 50000 µs（50 ms）**与**连续采样周期 200 ms**。

- `setMeasurementTimingBudget()` 单位为 µs；`startContinuous()` 单位为 ms（两 API 单位不同，勿混）。
- `startContinuous()` 的周期必须 ≥ 测量预算 + 芯片内部开销（实测建议留 ≥ 2× 余量），否则 `read()` 会频繁报 `timeoutOccurred()`。
- 若 VL53L1X 模块未自带 I2C 上拉电阻（裸模块/裸芯片），请在 GPIO1↔3.3V、GPIO2↔3.3V 各加 4.7 kΩ~10 kΩ 上拉；`Wire.begin()` 默认不开 ESP32 内部上拉，缺上拉会导致通信不稳。Pololu / Adafruit 这类分线板通常已板载 10 kΩ 上拉，无需再加。

#### 光敏电阻（光照传感器）

| 光敏电阻引脚 | 连接 |
|--------------|------|
| VCC | 3.3V |
| GND | GND  |
| AO  | GPIO3 (ADC1_CH2) |

建议在光敏电阻与红外补光灯之间加遮光隔板，避免补光灯自身光照到光敏电阻造成误判。

#### 红外补光灯（含 SS8050 低边开关）

淘宝主流 2-pin 红外补光灯模块**只有 V+/V- 两根线**，无控制脚。为保留软件开关能力，在 IR 灯与 GND 之间串一颗 NPN 三极管做**低边开关**，GPIO47 经 1 kΩ 限流电阻驱动基极：

```
   ┌───────── IR 灯 V+
   │
   │     ┌── IR 灯 V- ──┐
   │     │              │
ESP32 USB 5V  (VIN)      │
   │     │              │
   │     └── SS8050 C    │
   │              │      │
   │         SS8050 E ───┴── GND（与 ESP32 GND 共地）
   │              ▲
   │              B
   │              │
   └──[1kΩ]── GPIO47
```

- **三极管选型**：3W/5V 灯珠满载 ≈ 600 mA。**推荐 SS8050**（NPN，Ic=1.5A，TO-92 封装，几毛钱一颗）。S8050（Ic=500 mA）满载偏紧，长时工作可能过热——不推荐。
- **基极限流**：**220 Ω**（**不要用 1 kΩ 或 4.7 kΩ**——基极电流不足会导致三极管欠饱和，IR 灯只有 ~40% 亮度且三极管自身严重发热）。220 Ω 使基极电流 ≈ (3.3 − 0.7) / 220 ≈ 12 mA，远低于 GPIO47 的 40 mA 绝对上限，SS8050 在此电流下充分饱和（Vce(sat) ≤ 0.3V），C-E 压降低，IR 灯实际功率接近 3W 满载。
- **工作逻辑**：`digitalWrite(PIN_IR_LIGHT, HIGH)` → SS8050 导通 → 灯亮；`LOW` → 灯灭。代码逻辑（`isBright()` 判断后切换）与原方案完全一致，**不需要改 `esp32out.ino`**。
- **去耦建议**：SS8050 切换瞬间会在 5V 线上产生毛刺，建议在 IR 灯 V+/GND 之间并一颗 **100 nF 陶瓷电容**（必装，防 WiFi/相机高频干扰，¥0.01）。100 µF 电解电容可选（用于平滑低频波动，空间紧张可省）。
- **替代方案**：若未来 IR 灯改用独立 24V/12V 电源，可在 GPIO47 与 IR 灯之间改插一颗光耦（如 PC817），实现电气隔离，接法类似。

> IR 灯 V+ 直接取自 **ESP32 USB 5V 引脚**（详见 §4），不需要为 IR 灯单独配独立 5V 电源；若所用 USB 口供电能力紧张（老式 USB 2.0 口仅 500 mA），改用独立 5V 电源也可。

波长建议 850nm 或 940nm，并确认摄像头已拆除 IR-CUT 滤光片（OV2640 默认带 IR-CUT，需更换或拆除）。

#### OV2640 摄像头（板载）

GPIO 由 `src/esp32out.ino` 中的 `camera_config_t` 固定（`XCLK=15, SIOD=4, SIOC=5, D0=11, D1=9, D2=8, D3=10, D4=12, D5=18, D6=17, D7=16, VSYNC=6, HREF=7, PCLK=13`），不可改动。

## 3. 门内节点（`esp32in`）连线

门内节点同时承担"执行（开门）+触发（雷达首次触发时拍单帧留存并直接请求开锁）"两个职责，因此也需要 OV2640；不需要补光灯（室内一般有环境光），也不需要光敏。

### 3.1 GPIO 总览

| GPIO | 用途 | 方向 | 备注 |
|------|------|------|------|
| GPIO1  | I2C SDA          | I/O  | 雷达总线数据 |
| GPIO2  | I2C SCL          | OUT  | 雷达总线时钟 |
| GPIO14 | 舵机 1 PWM（把手） | OUT | 50Hz，`LEDC_CH0` |
| GPIO21 | 舵机 2 PWM（推拉门） | OUT | 50Hz，`LEDC_CH1`（确认板载未占用，详见 §3.2） |
| GPIO38 | VL53L1X XSHUT    | OUT  | 上电时拉低→高，启用 |
| GPIO39 | 保留                 | —    | 当前悬空，留作未来 XSHUT2 |

摄像头占用 GPIO4-13、15-18（与门外节点完全相同，板载固定）。

### 3.2 模块连接

#### VL53L1X × 1（雷达：出门触发 + 通过检测）

接线与门外节点完全相同（XSHUT 接 GPIO38），默认 I2C 地址 `0x29`，初始化流程见 §2.2。

雷达单点布设，对准门缝中心：

- 用于**出门触发**：雷达在 `INDOOR_OPEN_DISTANCE_CM`（默认 10 cm）内 → 拍单帧 JPEG + `0x9` 上报服务端 → 服务端直接开锁（不跑 YOLO）。
- 用于**进入通过检测**：门处于 `open` 状态且 `expectedPassage==indoor` 时，门内雷达触发 → 上发 `0x7{passage}` → 服务端关门。

#### OV2640 摄像头（板载，单帧拍照）

GPIO 与 `esp32out.ino` 完全一致；`camera_config_t` 在 `src/esp32in.ino` 中硬编码（`XCLK=15, SIOD=4, SIOC=5, D0=11, D1=9, D2=8, D3=10, D4=12, D5=18, D6=17, D7=16, VSYNC=6, HREF=7, PCLK=13`），不可改动。

**注意**：门内 ESP32-S3-CAM 上的摄像头**仅在雷达首次触发的瞬间**初始化一次，拍完单帧立即 `esp_camera_deinit()`；不持续抓拍。重复触发需要等 `catSessionActive` 复位（猫离开雷达范围后）。

#### 舵机 1（门把手下拉）

| 舵机线 | 连接 |
|--------|------|
| 红色（VCC） | 5V 独立电源（**不要**接 ESP32 5V 引脚） |
| 棕色（GND） | GND（与 ESP32 GND 共地） |
| 橙色（信号） | GPIO14 |

PWM：50Hz，脉宽 500–2500µs（0°–180°）。
- 初始（释放把手）：0°（脉宽 500µs）
- 下拉把手：60°（脉宽约 1166µs）

#### 舵机 2（推拉门）

| 舵机线 | 连接 |
|--------|------|
| 红色（VCC） | 5V 独立电源 |
| 棕色（GND） | GND |
| 橙色（信号） | GPIO21 |

PWM：50Hz，脉宽 500–2500µs。
- 初始（关）：0°
- 开门 15cm 缝：根据现场机械结构标定（典型 90°）

> **GPIO21 板兼容性**：部分 ESP32-S3-CAM 板（典型如 AI-Thinker 早期版本）将 GPIO21 接到了**板载白光 LED**（active-low）。GOOUUU / 大多数 ESP32-S3-CAM 变体一般无此 LED，可用；若所用板型 GPIO21 被 LED 占用，请将 `PIN_SERVO2` 改为其他空闲 GPIO，并同步更新 §3.1 表与 `src/esp32in.ino` 中的 `PIN_SERVO2` 定义。

> 评估报告指出，使用 SG90/MG996R 直接推门存在扭矩不足风险。生产前应改用 **猫 flap 方案** 或 **12V 直线推杆**；此处仅按方案文档保留舵机接口。

## 4. 供电

| 模块 | 电压 | 来源 |
|------|------|------|
| ESP32-S3-CAM × 2 | 5V（板载 LDO 转 3.3V） | USB 或 5V 适配器（两侧独立） |
| VL53L1X × 2（每侧 1 片） | 3.3V | ESP32 3.3V 引脚 |
| 光敏电阻 | 3.3V | ESP32 3.3V 引脚（仅门外） |
| 红外补光灯 | 5V（≤600 mA） | ESP32 USB 5V 引脚（经 SS8050 低边开关，详见 §2.2）；USB 口供电不足时改用独立 5V 电源 |
| 舵机 × 2 | 5–6V（≥2A） | **独立 5V 电源**（仅门内） |

所有外设的 GND 必须与对应侧 ESP32 的 GND 共地。**两侧 ESP32 之间禁止用导线直接共 5V 或共 GND**（避免地环路，以及雷击/浪涌沿电源线窜入两侧的风险）；两侧之间仅通过 WiFi（路由器/交换机）通信，不存在电源/地线直连。

## 5. 关键注意事项

1. **当前每侧仅 1 片 VL53L1X**：默认 I2C 地址 `0x29` 直接使用，**无需 XSHUT 地址分配时序**（单传感器不存在地址冲突）。代码仍会驱动 XSHUT 做一次硬复位（LOW→HIGH 各 10 ms，见 §2.2）。如果未来要加第 2 片，恢复 `0x29`/`0x30` 地址分配即可；当前代码未保留 `radar2` 实例与 `PIN_XSHUT2`（GPIO39 悬空）。
2. **门内也用了 ESP32-S3-CAM**：原方案文档曾建议门内降级为 ESP32-C3（评估报告 4.1 节），实际实施为对称双 ESP32-S3-CAM 以保留相机抓帧能力。
3. **雷达检测需 ≥ 2 次采样综合判断**，避免抖动误触（参见 `catPresent()` / `passageDetected()` 实现）。
4. **光敏电阻做防抖**：连续多次采样后才切换 IR 灯状态。
5. **关门安全（未实现）**：在门缝处增加对射式红外或压力感应条，关门时检测到障碍物立即反向开门（评估报告「🔴 关门安全检测」项）——**当前实现未含此功能，上线前必须补齐**。
6. **断电/断网降级**：WiFi 断开时 ESP32 应进入本地降级（仅 PIR + TOF 简单判断）——当前未实现。
7. **超时保护**：开门后若 30s 内猫未通过，服务端自动下发关门指令。
8. **GPIO 资源**：OV2640 占 14 pin（4-13、15-18）。两侧板剩余可用 GPIO 均为 5 个：室外侧占 `GPIO1、2、3、38、47`（I2C + 光敏 + XSHUT + IR 灯）；门内侧占 `GPIO1、2、14、21、38`（I2C + 2× 舵机 + XSHUT）。门内**已无任何剩余 GPIO**，如需加补光灯必须换用 GPIO 扩展芯片或精简舵机信号线。
9. **GPIO3 是 ESP32-S3 strapping pin**（JTAG 信号源选择）：光敏电阻分压电路必须保证**上电/复位瞬间 GPIO3 为低电平或高阻**，禁止对其做强上拉，否则可能进入非正常启动模式。ADC1_CH2 在系统起来后正常使用无问题。
10. **I2C 上拉**：`Wire.begin()` 默认不开 ESP32 内部上拉。VL53L1X 的 SDA/SCL 必须有外部上拉——大多数分线板（Pololu、Adafruit 等）已板载 10 kΩ 上拉，直接接线即可；若用裸模块/裸芯片，请外加 SDA↔3.3V、SCL↔3.3V 各 4.7 kΩ~10 kΩ 上拉。
